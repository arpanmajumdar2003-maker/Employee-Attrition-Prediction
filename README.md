# Employee Attrition Prediction for HR

## Project Overview
This project predicts employee attrition using Machine Learning and the IBM HR Analytics Employee Attrition dataset.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Algorithm
Random Forest Classifier

## Accuracy
86.73%

## Features
- Data Preprocessing
- Data Visualization
- Employee Attrition Prediction
- Feature Importance Analysis
- Model Evaluation

## Output
Predicts whether an employee is likely to leave the company or stay.
